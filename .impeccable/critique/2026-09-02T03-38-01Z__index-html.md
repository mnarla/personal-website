#### Priority Issues
- **[P1] Resume CTA Target Ambiguity**:
  - *Why it matters*: Both the header `RESUME ↗` CTA and the footer credentials card currently link to `https://github.com/mnarla`. When recruiters click "VIEW RESUME", landing on a GitHub profile creates immediate friction.
  - *Fix*: Connect to a direct viewable PDF or Google Drive resume link.
  - *Suggested command*: `/impeccable clarify`
- **[P2] Lack of Visual Proof for Spatial / Vision Work**:
  - *Why it matters*: For high-complexity visual systems like *UCSC Rocket Team video stitching* and *Formova exercise kinematics*, text descriptions tell rather than show. Evaluators want to see the homography output or landmark tracking.
  - *Fix*: Embed subtle technical wireframe schematics, architecture flowcharts, or preview stills inside project card drawers.
  - *Suggested command*: `/impeccable delight`
- **[P2] Card-Level Click Affordance**:
  - *Why it matters*: In `.project-card`, only the title text and the small footer link are clickable. Clicking anywhere else on the elevated card does nothing, requiring unnecessary pointer precision.
  - *Fix*: Stretch the primary link anchor or add a card-wide click handler so the entire surface acts as an interactive target.
  - *Suggested command*: `/impeccable polish`
